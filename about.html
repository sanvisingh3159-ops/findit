About FindIt

Connecting lost belongings with their rightful owners.

What is FindIt?

FindIt is a campus lost and found portal. Students can report items they have lost, report items they have found, search through all reported items and contact the owner to claim them. It helps belongings get back to their owners quickly.

How it works

1. Report a lost or found item with its details and a photo. 2. Search the listings by name, category or status. 3. Reunite by contacting the owner and marking the item as claimed.

Technologies used

  • HTML
  • CSS
  • JavaScript
  • localStorage
  • Git & GitHub
  • VS Code
